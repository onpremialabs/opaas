On-Prem AI Audit Suite · onpremIA Labs

Audit the AI you already run.

OPAAS looks at a deployment that is already running — its models, its agents, the system they form — measures how each performs and behaves and how auditable it is, and turns the result into a signed certificate anyone can verify offline. Per category, with intervals. Never one score.

Start an audit Read the guide ↗
$ cd <the environment's folder>
$ opaas
The environment is the folder you start from: New audit takes it as its scope.

The pipeline

  1. 01ScopeAn environment's folder, or the whole machine
  2. 02ScanEngines, models, agents, stack — read-only
  3. 03ChooseThe whole system, or only what you tick
  4. 04Auditbench A–E · smith · inquest · swarm
  5. 05ReportPer category, with intervals; what was not measured, said
  6. 06CertificateVerifiable offline by a third party
